🚀 Requirement Ambiguity Analyzer (RAA)

A web-based AI application that analyzes software requirements to detect ambiguity, improve clarity, and generate professional rewrites.

🔗 Live Demo

👉 https://requirement-ambiguity-analyzer.onrender.com/

⚠️ Note: The app is hosted on Render (free tier), so the first load may take a few seconds.

✨ Features
Ambiguity detection in requirements
Grammar correction
Professional rewrite generation
Requirement quality scoring
Realtime text analysis
File upload support
Dashboard with statistics
History tracking
🛠 Technologies Used

Python, JavaScript, HTML, CSS, FastAPI, Groq API (LLaMA 3), Chart.js, Render, Git, GitHub

⚙️ How to Run Locally
git clone <your-repo-link>
cd your-project-folder

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt

set GROQ_API_KEY=your_api_key

uvicorn backend.main:app --reload

Open in browser:

http://127.0.0.1:8000
☁️ Deployment

This application is deployed using Render, which hosts both backend and frontend and provides a public URL for access.

📌 Project Description

This project uses AI to analyze requirement text, identify ambiguity, correct grammar, and generate a clearer and more professional version along with a quality score.
